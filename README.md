# Higuchi Publisher

Draft articles, prepare text and illustrations for Dzen, and export to Markdown or HTML. The interface is in Russian. Requires desktop Obsidian 1.13.0 or later.

## Установка и первая статья

1. В Obsidian откройте «Настройки» → «Сторонние плагины» → «Обзор». Найдите **Higuchi Publisher**, нажмите «Установить», затем «Включить». Поиск по каталогу будет доступен после публикации карточки плагина.
2. Откройте Publisher по значку пера или через палитру команд. Подтвердите создание папки статей и нажмите «Создать статью».
3. Когда текст готов, нажмите «Подготовить для Дзена». Проверьте статью в ширине телефона, при необходимости обрежьте скриншоты и соберите папку с иллюстрациями. Вставьте текст и загрузите иллюстрации в черновик Дзена.
4. После переноса отметьте эту версию. При следующих правках Publisher покажет изменившиеся фрагменты и подписи.

Статьи, изображения и экспорт хранятся в вашем хранилище. Publisher работает локально. Для переноса статьи откройте Дзен в своём браузере.
