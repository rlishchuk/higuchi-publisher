# Higuchi Publisher

## Установка

В настольном Obsidian 1.13.0 или новее откройте «Настройки» → «Сторонние плагины» → «Обзор». Найдите **Higuchi Publisher**, нажмите «Установить» и «Включить».

## Первая статья

1. Откройте Publisher по значку пера или через палитру команд. Подтвердите папку для статей и создайте первую статью.
2. Нажмите «Подготовить для Дзена». Проверьте вид статьи в ширине телефона, при необходимости обрежьте скриншоты и соберите папку с пронумерованными иллюстрациями.
3. Скопируйте заголовок, текст и подписи в черновик Дзена. Загрузите картинки из подготовленной папки.
4. Отметьте перенесённую версию. После следующих правок Publisher покажет изменившиеся фрагменты и подписи.

Статьи и изображения обрабатываются в вашем хранилище. Publisher записывает данные в буфер обмена по нажатию кнопки копирования. Сборка бесплатна для личного и коммерческого использования.
